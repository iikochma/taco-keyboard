\# Taco Keyboard



images/keyboard-top-view.jpg



A highly ergonomic custom mechanical keyboard designed using KiCad, QMK, and Shapr3D.



The keyboard uses a single-piece design with approximately 60° tenting, integrated pointing devices for both hands, and a highly optimized keymap inspired by the Hands Down layout and Ben Vallack's 18-key keyboard concepts.



\## Key Features



\- 29-key custom layout ("30% keyboard")

\- Approximately 60° tenting and aggressive inward rotation

\- Dual integrated trackpads

\- Custom reversible PCB designed in KiCad

\- Custom QMK firmware

\- Custom 3D-printed enclosure designed in Shapr3D



\## Design Goals



The project was created to explore extreme ergonomic keyboard design while maintaining high typing efficiency.



The keymap is heavily inspired by the Hands Down layout and Ben Vallack's 18-key workflow. While the keyboard contains 29 keys, the majority of daily typing is performed using approximately 20 keys combined with layers and modifiers.



The layout was further optimized for LaTeX-heavy workflows, reducing hand movement for frequently used symbols and commands.



\## Hardware



A single reversible PCB design is used for both sides of the keyboard, reducing manufacturing complexity and cost.
